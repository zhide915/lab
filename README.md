# lab

One home for my throwaway experiments.

Each folder in the root is an experiment: one question, answered in whatever language or framework fits it. An experiment holds its own toolchain and dependencies, so you can run it on its own.

## Add an experiment

1. Create a folder, and name it with a short slug of the question, such as `bun-vs-node-http`.
1. In the folder, create a `README.md` that states the question, the answer, how to run the code, and the state of the experiment.
1. Add a line for the experiment to the list in this README, with a link to its folder.

An experiment is in one of the following states:

- **Open**: the question has no answer yet.
- **Done**: the README states the answer.
- **Abandoned**: the experiment stopped before an answer, and the README says why.
- **Moved**: the experiment grew into its own repository, and the README links to it.
